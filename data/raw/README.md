# data/raw/ — 採用データ(生データ)

**方針(US-1): 米国市場の「銘柄別ニュース + 市場全体ニュース + yfinance価格」でテキストの予測上の寄与を検証する。**
このディレクトリのファイルは**書き換えない**(ファイルは読み取り専用、整合性は `CHECKSUMS.md5` で確認)。
加工は `data/raw/` を入力にして、`data/interim/`、`data/processed/` に出力する。
データ本体はgit管理外(`.gitignore`)。このREADMEと `CHECKSUMS.md5` だけを追跡する。

## 検証済みの注意点(加工時に必ず考慮)
**news_price_events**
- `forward_return` = `|Close(t+1)/Close(t) − 1|`(絶対値)。**方向の情報はない**。`market_impact` はその全体三分位(0/1/2)。→ 目的変数は価格から作り直す。
- `Close` は配当・分割調整済み。始値・高値・安値・出来高はない。
- ニュースは取引日tの窓(9〜16時)に入り、ラベルは「tの終値→t+1の終値」。ニュース当日の反応(多くはt日中)がラベルに入らない疑い。`time_window` の定義は未確認。
- 同一(銘柄,日)に複数行(平均1.38窓)があり、ラベルを共有する → 日単位でtrain/testを分ける。
- 約34%(75,237行)の見出しが複数銘柄に共通の汎用見出し(「Stocks Hitting 52-Week Highs」等)。
- AAPL / AMZN / MSFT / META / JPM / XOM / INTC / AMD / WMT は0行。銘柄の選定理由は不明。
- 2020年6月で終了。テスト期間に2020年のコロナ急落が入ると分布がずれる(2018以降を30%でテストにすると多数派が0.387)。
- 前日の変動とラベルの順位相関が約0.32 → 価格のみのベースラインが強い。

**NYT見出し**
- `Label` はKaggle DJIAの翌営業日Labelと約90%一致(同日は48.6%)。指数は明記なし。→ 自分で価格(`^DJI`)から作り直す。
- 1日約84語、小文字化済み、見出しのみ。
