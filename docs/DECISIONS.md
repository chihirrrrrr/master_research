## 2026-10-05
- **数値データ(A0)を作成した**: yfinanceから株式220銘柄と市場・マクロ27系列を取得(2008-01〜2021-12、`data/raw/prices_yfinance/20261005/`)。特徴量27個と目的変数の候補8列を `data/processed/` に作成。検証: ①作者の`forward_return`を100%再現(156,600行)、②特徴量は前日までの情報(行tの特徴量と日tのリターンの相関-0.024、1日ずらすと1.000)、③リークのテストが、シフトを外した変異コードを検出する。「小さく始める」は期間ではなく**特徴量の数**(期間は全期間)。
- 取得できなかった株式はAET・ESRX・TWX(買収された会社、ニュース3,131行=1.4%)。`close`は分割調整済み・配当未調整、`adj_close`は配当・分割とも調整済み。
- 方針までをGitHubにpushした(`b9a9465`)。
- **研究の骨格をアブレーション(A0〜A3)に決定**: A0=数値のみ、A1=+NYT(世界情勢)、A2=+news_price_events(銘柄ニュース)、A3=両方。**予測の単位は個別株(220銘柄)×取引日**。主な比較は寄り前ニュースがある(銘柄,日)の同じ行。A0の特徴量セットは、テキストを足す前に検証期間で決めて固定する。
- 数値データの候補(銘柄・市場・金利・為替・商品・テック・業種)を RESEARCH_PLAN §3-2 に記録(未確定)。yfinanceで、2008年以降の主要ティッカーが取得できることを確認した(2年金利と過去の財務は取れない)。
- **運用の土台を整えた**: `requirements.txt`・`.venv`・`Makefile`、`tests/`(rawのデータ契約)、`configs/split.yaml`、`results/runs/`(1実験1ディレクトリ)、`docs/OPERATIONS.md`。xgboostにはOpenMP(`brew install libomp`)が必要。
- **研究方針をv0.2に更新**: 予測時点を取引日の寄り前とし(提案)、予測の時間幅(ギャップ/日中/当日/翌日)を研究の軸に加えた。NYTは補助に下げ、市場全体テキストの主役は news_price_events の市場・ETF見出しにする。根拠: 09時窓の92.4%(97,776行)が元の時刻9:30より前、NYTは「World」欄のみ。
- 分割は作者の推奨(2009〜2017 / 2018〜2019 / 2020)を暫定採用(`configs/split.yaml`)。
- **学部のGDELTデータは修士で使わない。** 理由: 企業同定の誤検出(SO 97.7%、DOW 94%が社名なし)、日付のみで時刻なし、週末ニュースの破棄、多数派ベースライン(約54%)を超えない結果。評価の詳細は docs/legacy/ と DATASET_評価_修士.md。
- **データはUS-1を採用**: `news_price_events`(銘柄別・時刻つき)+ NYT見出し(市場全体)+ yfinance価格。理由: 時刻・銘柄・規模・長期が揃い、ラベルを価格から作り直せる。弱点(2020年6月で終了、本文なし、一部の大型株なし)は、中程度〜低と判断。他市場での頑健性確認(CROSS)は後で検討。
- **検討した14データは、リポジトリ外の `修士研究/検討したデータセット/` に置く。** 理由: GitHubへpushする量を減らす。採用分だけ `data/raw/` にコピー(md5で一致を確認)。
- **学部GDELT(約8GB)も、リポジトリ外の `修士研究/学部時代のGDELT研究/` に移す。** 理由: 100MB超のファイル39個(7.8GB)、鍵JSON・`.env`、`.venv` がコミットされており、GitHubにpushできない。
- **gitの履歴を作り直す**(旧2コミットを破棄)。理由: GitHub側は空でpush前、学部データの実体はディスクに残る。
- **データ構成は `data/{raw,interim,processed}`。** `raw/` は読み取り専用で、本体はgit管理外(README・CHECKSUMS.txtのみ追跡)。
- **目的変数は未決。複数を比較する**(方向・リターン・超過リターン・ボラティリティ)。検証期間だけで比較し、テスト期間は最後まで見ない。
