## 1. 研究の問い
金融ニュースのテキスト特徴を、価格由来の数値特徴量に**加えると**、株価の予測は、価格のみのモデルより改善するか。

サブクエスチョン:
- (a) 銘柄別ニュースと、市場全体のニュースのどちらが寄与するか。
- (b) 目的変数(方向・リターン・ボラティリティなど)によって、テキストの寄与は変わるか。
- (c) テキスト表現(感情スコア・埋め込み)で、寄与に差はあるか。
- (d) **ニュースの効果は、どの時間幅に現れるか**(翌営業日 / 5営業日)。← v0.2で追加、v0.6で改訂

### 3-2. 数値データ(A0)の候補 — **未確定**(提案。実際に取得して確認済みのもの)
考え方: (1) A0は「テキストが**追加で**効くか」の基準。弱すぎる(不公平)も、多すぎる(過学習・解釈困難)もよくない。(2) 「銘柄の状態・市場の状態・景気とリスクの状態」の3層で、解釈できる少数の特徴量にする。(3) すべて**当日(t)の終値までの値**を使う(t の引け後に予測するため。過去の窓は t までの履歴)。(4) **A0の特徴量セットは、テキストを足す前に検証期間で決めて固定する**(あとから調整しない)。

| 層 | 特徴量(例) | 元データ(yfinance) | 取得 |
|---|---|---|---|
| 銘柄 | 過去リターン(1・5・20日)、実現ボラ(5・20日)、日中レンジ、直近のギャップ、出来高比(出来高/20日平均)、移動平均・52週高値からの距離 | 各銘柄のOHLCV | ○ 220/223銘柄 |
| 市場 | S&P500のリターン・ボラ、VIXの水準と変化、VIX3M/VIX(期間構造) | `^GSPC`、`SPY`、`^VIX`、`^VIX3M` | ○ |
| 金利 | 10年金利の水準・変化、10年−3か月のスプレッド | `^TNX`、`^IRX`(`^FVX`、`^TYX`も) | ○(2年はFREDのみ) |
| 為替 | (除外) | — | ✕ 含めない(2026-10-08の決定。2008年のドル円・ユーロドルに取得元の日付の崩れ)。特徴量からも外した |
| 商品 | 原油(WTI・Brent)、銅、金の変化 | `CL=F`、`BZ=F`、`HG=F`、`GC=F` | ○(WTIは2020-04が負値) |
| テック・業種 | SOX−NASDAQの相対、その銘柄の業種のETF | `^SOX`、`^IXIC`、`^NDX`、`XLB XLE XLF XLI XLK XLP XLU XLV XLY` | ○(銘柄→業種の対応表が別途必要) |
| カレンダー | 曜日、月、決算日の前後 | `earnings_dates` | 決算日は銘柄ごとの網羅性を要確認 |
| 任意 | 信用スプレッド、原油・金・債券のボラ、Russell2000 | `HYG`、`LQD`、`^OVX`、`^GVZ`、`^MOVE`、`^SKEW`、`^RUT` | ○(2008〜) |

**作成済み**: `python -m src.features.numeric` で `data/processed/numeric_features.parquet`(25個、743,535行)と `numeric_targets.parquet`(目的変数12列)ができる。特徴量はすべて当日(t)の終値までの情報(t+1 以降を使わないことをテストで確認)。業種ETFと決算日は未実装。
**取れないもの**: 過去の財務諸表(取得できるのは直近約5期)、時価総額・業種の履歴(現在値のみ)、銘柄ごとのオプション・IV、2009〜2020の分足、アナリスト予想。→ 必要なら別のデータ源(FRED、SEC EDGAR)。

## 4. 予測時点と目的変数
### 4-1. 予測時点: 取引日 t の引け後(決定 2026-10-05)
- **起点**: 取引日 t の終了後(引け後。翌営業日 t+1 の寄り前)。**説明変数は、当日(t)のニュースと数値(過去の履歴を含む)**。目的変数は t+1 以降の価格だけで作る。
- **ニュース**: `news_price_events` の、取引日 t の行(9〜15時の窓)をすべて使う。作者の処理により、寄り前のニュースは t の寄り付き、引け後のニュースは次の取引日に寄せられている。取引日 t の16:00以降の437行は除外する。
- **対象の(銘柄,日)**: 158,680。うち寄り前の窓を含む97,776、日中の窓だけ60,904。価格がある220銘柄で156,422(すべて目的変数が計算できる)。1日に複数の窓がある(銘柄,日)は42,366(26.7%)。
- この時間関係は、作者のラベル(日 t のニュース → t の終値から翌日の終値)と同じ。**ニュース当日の反応は、当日の数値(t の終値までの値)に既に入っている**ので、A2は「ニュースが、当日の値動きや出来高で説明できない部分を、その後の値動きについて予測するか」を測る。
- 日次価格では、ニュースの時刻から終値までを分けられない(yfinanceの分足・時間足は2009〜2020に使えない)。ニュースの時刻の違い(寄り前 / 日中)は、感度分析で扱う。

### 4-2. 目的変数(決定 2026-10-05。詳細は `docs/VARIABLES.md`)
- **種類**: **リターン(回帰)**と**超過リターン**(銘柄 − SPY)。方向(上昇/下降)は、予測値の符号から導く副次的な評価。ボラティリティは、今回は主な目的変数から外した(必要なら後で追加)。
- **時間幅**: **翌営業日から5営業日の平均**(主)。起点(t の引け後)から見て、t+1 から t+5 の日次リターン(前日終値→終値)の平均(**t は含まない**)。比較用に翌営業日(`ret_fwd1`)も作る。
- 根拠: 学習期間のSPYで見積もると、方向・リターンはどの時間幅でも予測しにくい(R²≒0)。平均を取ると、変動は予測しやすくなる(R² 0.18 → 0.41)が、ラベルが重なる(自己相関0.9前後)。ニュースがどの時間幅に効くかは、翌営業日と5営業日の比較で調べる。

| 研究 | 主 | 副 |
|---|---|---|
| 研究1(S&P500) | `spy_ret_fwd5` | `spy_ret_fwd1` |
| 研究2(個別株) | `ret_fwd5`、`ex_ret_fwd5` | `ret_fwd1`、`ex_ret_fwd1` |

- 研究1は、市場そのものなので超過リターンは使わない(無リスク金利を引いても、日次の平均がSPYの日次標準偏差の0.2%)。
- t+1 の寄り付きのギャップ・日中(`ret_gap_fwd1`・`ret_intraday_fwd1`)は、診断用のみ(主実験では使わない)。
- 変更する場合は、理由を docs/DECISIONS.md に記録する。

## 5. 実験設計: 2段階のアブレーション
どちらの研究も、**同じ行・同じ分割・同じモデルで、入力だけを変える**。足すのは1回に1種類。時刻のルール(§6)を守る。A0(m)の特徴量セットは、テキストを足す前に確定して固定する(確定の手順は、分割とあわせて決める)。

### 5-1. 研究1(市場レベル): 世界情勢のテキストは、市場全体の予測に効くか
NYTは銘柄情報を持たず、説明できるのは**市場全体の動き**だけなので、予測対象をS&P500にして日単位で検証する。

| 条件 | 入力 | データ |
|---|---|---|
| A0m | 市場・マクロの数値のみ(13個 + 曜日・月2個 = 15個) | yfinance(`make features` の市場・マクロ列) |
| A1m | A0m + 世界情勢テキスト | + NYT(**前日までの見出し**) |
| (任意)A2m | A1m + 市場・ETF見出し | + news_price_eventsのETF見出し |

- **予測対象**: S&P500(SPY)のリターン。単位は日。目的変数は `spy_ret_fwd5`(主)と `spy_ret_fwd1`(副)。
- **サンプル**: 研究期間(2009-04-29〜2020-06-12)でSPYの営業日2,801日(NYTと重なるのは2,799日)。NYTの全期間(2008〜2021、3,522日)は頑健性確認に使う。**分割は `docs/VARIABLES.md` §6**。
- **NYTの表現**: FinBERTの感情・埋め込み(+PCA)、キーワード。1日約84語で入力長に収まる。
- **検出力の限界**: 日数が少ない(約2,800日)。5営業日平均のラベルは隣の日と大きく重なる(自己相関0.9前後)ので、実質の独立サンプルは、さらに約1/5になる。評価・検定は、この重なりを考慮する(分割とあわせて決める)。
- 補助: NYT全期間(2008〜2021)での再現、作者のタスク(S&P500の翌日の方向)との比較。

### 5-2. 研究2(銘柄レベル): 銘柄のニュースは、その銘柄の予測に効くか
**予測の単位: 個別株(220銘柄) × 取引日**。NYTやマクロは「全銘柄に同じ値を付ける特徴」として使う。

| 条件 | 入力 | データ | 調べること |
|---|---|---|---|
| A0 | 数値のみ(25個) | yfinance | 基準 |
| A1 | A0 + 世界情勢テキスト | + NYT(前日までの見出し) | 銘柄の予測でも世界情勢が追加で効くか |
| A2 | A0 + 銘柄ニュース | + news_price_events(当日のニュース) | 銘柄のニュースが、数値に追加で効くか |
| A3 | A0 + 両方 | A0 + NYT + news_price_events | 両方で、さらに良くなるか |

- **主な比較**: 「当日のニュースがある(銘柄,日)」(156,422行)の**同じ行**で、A0〜A3を比べる。補助: 全日で比べる(ニュースの有無をフラグにする)/ 数値の内訳(価格・出来高のみ、+マクロ)。
- NYTは全銘柄で同じ値なので、実質のサンプルは日数。**行を独立として扱わず、日付でまとめて評価する**(日付で分割、日ごとの損失で検定、日付のクラスタ)。
- 研究1でNYTが効かなければ、A1・A3でもNYTの寄与は小さいと予想される(確認する)。

### 5-3. 共通の設定
- テキスト表現: FinBERT感情(3次元)、埋め込み(+PCA)。必要に応じて他の表現を追加。
- 学習器: **主は XGBoost**(2026-10-08決定。学部の卒論と同じで、結果をつなげて比べられる)。**第2のモデルは系列モデルの GRU**(「木のモデル」と「系列のモデル」の2種類で、結論が変わらないか確認する。GRUは構造を固定して全条件で同じにする)。LSTM・素のRNNは使わない。履歴平均は「物差し」(モデルではなく、これを超えるかを見る)。LightGBM・ランダムフォレスト・AutoKerasは、必要になったら後で。
- **分割(学習・検証・テスト)**: 決定済み(2026-10-08)。時間順の walk-forward(拡張窓、年ごとに再学習)で、境界に4営業日の空き。開発と最終確認に分ける。詳細は `docs/VARIABLES.md` §6。`configs/split.yaml` に反映済み。
- 評価: 履歴平均に対する標本外R²、予測と実現の相関、符号の的中率。**A0との差の有意性**は、5日の重なりを補正した検定(Clark–West、HACラグ5以上)。詳細は `docs/VARIABLES.md` §6。
- ベースライン: 多数派、前日値、(銘柄平均)、数値のみ(A0 / A0m)。
- **感度分析**(研究2): 寄り前の窓を含む行(97,776)/ 日中の窓だけの行(60,904)/ 窓内の見出し数が1の行・複数の行 / 汎用見出し(複数銘柄に共通)を除く。

## 6. 時刻の整合(リーク防止)ルール
- **起点は取引日 t の引け後。** 特徴量は t の終値(以前)までに公開された情報だけ。目的変数は t+1 以降の価格だけで作る。「t より後の価格を変えても、行 t までの特徴量が変わらない」ことを `tests/` で保護する(未来を使う変異コードを検出できることも確認済み)。
- ニュースは、`news_price_events` の取引日 t の行(9〜15時の窓)を使う。元の時刻は `original_first_date` を使い、**t の16:00以降の437行(寄せられていない)は除外**する。窓内の見出しは、その1時間内に公開されたもの。
- 引け後・週末・祝日のニュースは、作者の処理により、次の取引日の行に入る(次の日の説明変数になる)。
- NYT見出しは、日付 D の見出しを、起点 t = D に使う。**公開時刻がない**ので、引け後に出た見出しが混ざる可能性があるが、いずれも t+1 の寄り前までの情報で、目的変数(t+1 以降)より前である。
- `news_price_events` のラベル(t の終値 → t+1 の終値の絶対リターン)は使わず、価格から §4-2 の目的変数を作る(再現は確認済み)。
- 2009〜2020は日次価格に対応付ける(分足・時間足は使えない)。
- yfinanceの調整済み価格は、取得日により変わりうる。取得日・バージョンを記録する。
