## 1. 研究の問い
金融ニュースのテキスト特徴を、価格由来の数値特徴量に**加えると**、株価の予測は、価格のみのモデルより改善するか。

サブクエスチョン:
- (a) 銘柄別ニュースと、市場全体のニュースのどちらが寄与するか。
- (b) 目的変数(方向・リターン・ボラティリティなど)によって、テキストの寄与は変わるか。
- (c) テキスト表現(感情スコア・埋め込み)で、寄与に差はあるか。
- (d) **ニュースの効果は、どの時間幅に現れるか**(寄り付きのギャップ / 日中 / 翌日)。← v0.2で追加

## 2. 学部との違い
| | 学部(卒論) | 修士 |

| 入力 | ニューステキストのみ | テキスト + 数値(価格・市場) |
| 目的変数 | セクターETFの上昇/下降 | **未決(種類と時間幅の組み合わせを比較)** |

## 3. データ(US-1)
| 役割 | データ | 状態 |
|---|---|---|
| 銘柄別テキスト(主) | `data/raw/news_price_events`(223銘柄、2009-04〜2020-06、時刻つき、ライセンスODC-By) | 採用済み |
| 世界情勢テキスト(A1) | `data/raw/nyt_headlines`(NYT「World」欄、2008〜2021。LabelはS&P500の翌日、CC0) | 採用済み |
| (任意)市場・ETF見出し | 同じデータのETF見出し(DIA・QQQ・IWMなど、29,110行) | 必要になったら作る |
| 数値(A0) | yfinance(§3-2) | **未取得** |

- NYTは「World」欄のみで、経済・市場の記事ではない(出典ページで確認)。市場との関連は間接的で、VIXや為替が世界情勢を一部織り込むため、**A1の効果は小さいかもしれない**。それもA1の結果として扱う。
- 既知の制約は `data/raw/README.md` を参照(ラベルが絶対リターンのみ、汎用見出し34%、2020年6月で終了、AAPL/AMZN等なし、説明とデータの不一致など)。評価: `docs/DATASET_評価_修士.md`。

### 3-2. 数値データ(A0)の候補 — **未確定**(提案。実際に取得して確認済みのもの)
考え方: (1) A0は「テキストが**追加で**効くか」の基準。弱すぎる(不公平)も、多すぎる(過学習・解釈困難)もよくない。(2) 「銘柄の状態・市場の状態・景気とリスクの状態」の3層で、解釈できる少数の特徴量にする。(3) すべて**前日(t-1)の終値までの値**を使う(寄り前に予測するため)。(4) **A0の特徴量セットは、テキストを足す前に検証期間で決めて固定する**(あとから調整しない)。

| 層 | 特徴量(例) | 元データ(yfinance) | 取得 |
|---|---|---|---|
| 銘柄 | 過去リターン(1・5・20日)、実現ボラ(5・20日)、日中レンジ、直近のギャップ、出来高比(出来高/20日平均)、移動平均・52週高値からの距離 | 各銘柄のOHLCV | ○ 220/223銘柄 |
| 市場 | S&P500のリターン・ボラ、VIXの水準と変化、VIX3M/VIX(期間構造) | `^GSPC`、`SPY`、`^VIX`、`^VIX3M` | ○ |
| 金利 | 10年金利の水準・変化、10年−3か月のスプレッド | `^TNX`、`^IRX`(`^FVX`、`^TYX`も) | ○(2年はFREDのみ) |
| 為替 | ドル指数、ドル円の変化 | `DX-Y.NYB`、`JPY=X`(`EURUSD=X`) | ○ |
| 商品 | 原油(WTI・Brent)、銅、金の変化 | `CL=F`、`BZ=F`、`HG=F`、`GC=F` | ○(WTIは2020-04が負値) |
| テック・業種 | SOX−NASDAQの相対、その銘柄の業種のETF | `^SOX`、`^IXIC`、`^NDX`、`XLB XLE XLF XLI XLK XLP XLU XLV XLY` | ○(銘柄→業種の対応表が別途必要) |
| カレンダー | 曜日、月、決算日の前後 | `earnings_dates` | 決算日は銘柄ごとの網羅性を要確認 |
| 任意 | 信用スプレッド、原油・金・債券のボラ、Russell2000 | `HYG`、`LQD`、`^OVX`、`^GVZ`、`^MOVE`、`^SKEW`、`^RUT` | ○(2008〜) |

**取れないもの**: 過去の財務諸表(取得できるのは直近約5期)、時価総額・業種の履歴(現在値のみ)、銘柄ごとのオプション・IV、2009〜2020の分足、アナリスト予想。→ 必要なら別のデータ源(FRED、SEC EDGAR)。
**最初のセット(案、約27個)**: 銘柄10 + 市場6 + 金利3 + 為替2 + 商品3 + SOX−NASDAQ 1 + 曜日・月 2。他は、必要になったら足す。

## 4. 予測時点と目的変数
### 4-1. 予測時点(提案): 取引日 t の寄り前(9:30 ET)
- **入力**: 前日の引け後から当日の9:30より前に公開された見出し + t-1 までの価格・市場の特徴量。
- 根拠(データで確認済み): `news_price_events` の「09時窓」は105,835行(全体の48%)で、そのうち**92.4%(97,776行)が、元の時刻(`original_first_date`)が当日9:30より前**。作者の処理が、「寄り前は当日9:30、引け後は次の取引セッション」に寄せているため、**前日の引け後・夜間・週末のニュースがこの窓にまとまる**。
- この97,776行は(銘柄,取引日)ごとに1行で、223銘柄・2009-04〜2020-06にわたる。
- 10〜16時の窓(114,136行)は、日次価格ではニュースの時刻から終値までを分けられない(yfinanceの分足・時間足は2009〜2020に使えない)。**主実験から外し**、感度分析で扱う。

### 4-2. 目的変数: 時間幅 × 種類を比較(**未決のまま比較**)
| 時間幅 | 定義 | 意味 |
|---|---|---|
| ギャップ | Close(t-1) → Open(t) | 寄り前ニュースへの即時反応。最も直接 |
| 日中 | Open(t) → Close(t) | 寄り付き後の動き |
| 当日 | Close(t-1) → Close(t) | ギャップ + 日中 |
| 翌日 | Close(t) → Close(t+1) | 作者のラベルと同じ。ニュースの持続効果 |

| 種類 | 内容 | 注意 |
|---|---|---|
| 方向 | 上昇/下降(分類) | 日次の方向は偶然に近く、改善を示しにくい |
| リターン | 回帰 | 難しいが、投資への含意が出しやすい |
| 超過リターン | 市場(`^GSPC`)調整後 | 市場全体の動きを除ける |
| 大きさ | \|リターン\|、ボラティリティ | 価格のみのベースラインが強い(前日変動との順位相関 約0.32) |

進め方: まず**数値のみ(A0)**で各目的変数の予測可能性を確認し、**検証期間だけ**で比較する(テスト期間は最後まで見ない。結果で目的変数を選ぶデータスヌーピングを避ける)。主・副の選定は、その結果と指導教員との相談で決める。作者のラベル(翌日の大きさ)は、この表の1つの条件として再現できる。

## 5. 実験設計: アブレーション(A0〜A3)
**予測の単位: 個別株(220銘柄) × 取引日**(2026-10-05承認)。NYTやマクロは「全銘柄に同じ値を付ける特徴」として使う。

| 条件 | 入力 | データ | 調べること |
|---|---|---|---|
| A0 | 数値のみ | yfinance(§3-2) | 基準 |
| A1 | A0 + 世界情勢テキスト | + NYT(前日までの見出し) | 世界情勢が、数値に**追加で**効くか |
| A2 | A0 + 銘柄ニュース | + news_price_events(寄り前) | 銘柄のニュースが、数値に追加で効くか |
| A3 | A0 + 両方 | A0 + NYT + news_price_events | 両方で、さらに良くなるか |

**比較のルール**: ①同じ行・同じ分割・同じモデルで、入力だけを変える。②足すのは1回に1種類。③時刻のルール(§6)を守る。④A0の特徴量セットは、テキストを足す前に検証期間で決めて固定する。
- **主な比較**: 「寄り前ニュースがある(銘柄,日)」(約96千行)の**同じ行**で、A0〜A3を比べる。
- **補助**: 全日で比べる(ニュースの有無をフラグにする)/ 指数(`^GSPC`)の予測(NYT本来のタスク)/ 数値の内訳(価格・出来高のみ、+マクロ)。
- テキスト表現: FinBERT感情(3次元)、埋め込み(+PCA)。必要に応じて他の表現を追加。
- 学習器: 線形モデル / XGBoost など。
- 分割: `configs/split.yaml`(暫定。作者の推奨: 学習2009〜2017 / 検証2018〜2019 / テスト2020)。内部は拡張窓のwalk-forward。同じ取引日の行は同じ側に置く。
- 評価: 分類はAUC・balanced accuracy・F1、回帰はRMSE(ボラは損失関数も検討)。**A0との差の有意性**は、日単位のブロックで検定する(方法は未決。Diebold–Mariano、ブートストラップなど)。
- ベースライン: 多数派、前日値、銘柄平均、数値のみ(A0)。
- **感度分析**: 窓内の見出し数が1のものだけ(純粋な寄り前: 61,386行)/ 複数のもの(36,390行。後続の見出しが9:30以降の可能性)/ 9:30〜9:59の見出しを含むもの / 10〜16時の窓。

## 6. 時刻の整合(リーク防止)ルール
- 予測時点(§4-1)までに公開された情報だけを特徴量にする。目的変数の期間は、その時点より後から始める。
- ニュースの元の時刻は `original_first_date` を使う(`time_window` は1時間に丸められ、9:30前後を区別できない)。
- 引け後(16:00以降)・週末・祝日のニュースは次の取引日に寄せる(作者の処理に従うが、**取引日 t の16:00以降の437行は寄せられていない**ので除外する)。
- `news_price_events` のラベル(t の終値 → t+1 の終値)は使わず、価格から §4-2 の目的変数を作る。
- 2009〜2020は日次価格に対応付ける(分足・時間足は使えない)。この整合ルールは、実装する時点で `tests/` のテストで保護する。
- yfinanceの調整済み価格は、取得日により変わりうる。取得日・バージョンを記録する。

## 7. 未決事項・要確認

- 上流データ *Daily Financial News for 6000+ Stocks* のライセンス(出典・ライセンスは data/raw/README.md に記録済み)
- yfinanceで取得できる範囲・欠損(特に `Open`、上場廃止・社名変更した銘柄)

- 計算資源(研究室のGPUサーバーを使えるか)
