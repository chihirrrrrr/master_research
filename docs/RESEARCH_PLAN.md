# 研究方針(たたき台)

**状態: 未確定項目あり。** 決まったことは docs/DECISIONS.md に記録し、ここを更新する。

## 1. 研究の問い
金融ニュースのテキスト特徴を、価格由来の数値特徴量に**加えると**、株価の予測は、価格のみのモデルより改善するか。

サブクエスチョン:
- (a) 銘柄別ニュースと、市場全体のニュースのどちらが寄与するか。
- (b) 目的変数(方向・リターン・ボラティリティなど)によって、テキストの寄与は変わるか。
- (c) テキスト表現(感情スコア・埋め込み)で、寄与に差はあるか。

## 2. 学部との違い
| | 学部(卒論) | 修士 |
|---|---|---|
| 入力 | ニューステキストのみ | テキスト + 数値(価格・市場) |
| 目的変数 | セクターETFの上昇/下降 | **未決(複数を比較)** |
| 単位 | 日 × セクター | 日 × 銘柄(+ 市場全体) |
| ニュース | GDELT(企業同定の誤検出あり、日付のみ) | 時刻つき見出し(銘柄別)+ NYT(市場全体) |
| 評価 | Accuracy中心 | ベースライン比較・walk-forward・複数指標 |

評価: `docs/DATASET_評価_修士.md`。

## 4. 目的変数(**未決: 複数を比較**)
| 候補 | 内容 | 注意 |
|---|---|---|
| 方向 | 翌営業日の上昇/下降(分類) | 日次の方向は偶然に近く、改善を示しにくい |
| リターン | 翌営業日リターン(回帰) | 難しいが、投資への含意が出しやすい |
| 超過リターン | 市場(S&P500など)調整後のリターン | 市場全体の動きを除ける |
| ボラティリティ | 翌営業日の\|リターン\|、実現ボラ | 価格のみのベースラインが強い(前日変動との順位相関 約0.32) |

進め方(案): まず価格のみのモデルで各目的変数の予測可能性を確認し、**検証期間だけで**比較する(テスト期間は最後まで見ない。目的変数を結果で選ぶデータスヌーピングを避ける)。主・副の選定は、その結果と指導教員との相談で決める。

## 5. 実験設計(案)
| モデル | 入力 |
|---|---|
| M0 | 価格のみ(前日変動、銘柄効果、市場変数など) |
| M1 | M0 + 市場全体テキスト(NYT) |
| M2 | M0 + 銘柄別ニュース |
| M3 | M0 + 両方 |

- テキスト表現: FinBERT感情(3次元)、埋め込み(+PCA)。必要に応じて他の表現を追加。
- 学習器: 線形モデル / XGBoost など。
- 評価: 日単位のwalk-forward(拡張窓)。同日・同銘柄の行は同じ側に置く。分類はAUC・balanced accuracy・F1、回帰はRMSE(ボラは損失関数も検討)。統計的な有意差の検定は方法を検討する(未決)。
- ベースライン: 多数派、前日値、銘柄平均、価格のみのモデル。

## 6. 時刻の整合(リーク防止)ルール
- ニュースの時刻(米東部時間)を取引日に割り当てる。**16:00以降は次営業日、週末・祝日も次営業日**に寄せる。
- 特徴量に使う情報は、予測の時点までに公開されたものだけにする。目的変数の期間は、その後から始める。
- `news_price_events` の `time_window` の定義と、ラベル(t の終値 → t+1 の終値)のずれは、検証してから採用する。
- yfinanceの分足・時間足は取得できる期間が限られる(要確認)ため、2009〜2020は**日次価格**に対応付ける。
