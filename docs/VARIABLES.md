# 目的変数と説明変数の運用方針

**状態: 決定(2026-10-05、同日に起点を変更)。** ただし、学習・検証・テストの**分割**と、モデル・評価指標・検定の細部は**保留**(RESEARCH_PLAN.md §5-3)。§2-6(過去の履歴の持たせ方)は**提案**(未実装)。
実装: `src/features/numeric.py`(`make features`)。定義を変えるときは、理由を docs/DECISIONS.md に記録し、A0〜A3 を全部作り直す。

## 0. 3つの原則
1. **予測の起点は、取引日 t の引け後**(翌営業日 t+1 の寄り前)。**説明変数は当日(t)までの情報**(当日のニュースと数値、その過去の履歴)。**目的変数は t+1 以降の価格だけ**で作る。
2. **説明変数と目的変数は別ファイル**にして、キーでだけ結合する(研究2は `(ticker, date)`、研究1は `date`)。
3. 標準化・外れ値処理・欠損補完など、**データから値を決める変換は、学習データだけで決めて**他に適用する。作成スクリプトは、これらを行わない(今のファイルは未変換)。

## 1. 目的変数
### 1-1. 定義
日次リターン `r_s` = 調整済み終値の前日比(前日終値 → 終値、配当・分割調整済み)。**夜間の動き(寄り付きのギャップ)を含む**。
「翌営業日から5営業日」= 起点(t の引け後)から見て、翌営業日 t+1 から t+5 までの5営業日(**t は含まない**)。

| 名前 | 定義 | 研究 | 役割 |
|---|---|---|---|
| `ret_fwd5` | 銘柄の mean(r_{t+1}, …, r_{t+5}) | 研究2 | **主** |
| `ex_ret_fwd5` | `ret_fwd5` − `spy_ret_fwd5`(市場調整の超過リターン) | 研究2 | **主** |
| `spy_ret_fwd5` | SPYの mean(r_{t+1}, …, r_{t+5}) | 研究1 | **主** |
| `ret_fwd1` / `ex_ret_fwd1` / `spy_ret_fwd1` | r_{t+1}(t の終値 → t+1 の終値)/ 銘柄 − SPY / SPY | 研究2 / 研究2 / 研究1 | 副(時間幅の比較: 翌営業日 対 5営業日) |
| `ret_gap_fwd1` `ret_intraday_fwd1` と、その `spy_`・`ex_` 版 | t の終値→t+1 の始値 / t+1 の始値→終値 | — | 診断用(主実験では使わない) |

### 1-2. 種類と超過リターン
- **種類は回帰(リターン)**。方向(上昇/下降)は、予測値の符号から導く副次的な評価。変動の大きさ(ボラティリティ)は、今回は目的変数から外した(必要なら後で追加)。
- **研究2の超過リターン** = 銘柄 − SPY(同じ営業日・同じ窓)。220銘柄の t+1〜t+5 の窓は、SPYの窓と日付が100%一致する(742,215行で確認)。ベータ調整(銘柄のベータ × SPY を引く)は採用しない(必要なら、t までの過去データでベータを推定して追加する)。
- **研究1(S&P500)は、超過リターンを使わない。** 市場そのものであり、無リスク金利(`^IRX`)を引いても、日次の平均がSPYの日次標準偏差の0.2%にすぎない(2009-04〜2020-06)。

### 1-3. 注意
- **5営業日平均は、隣の日と4/5重なる**(自己相関が0.9前後)。実質の独立サンプルは約1/5。評価・検定はこの重なりを考慮し、分割を決めるときに、境界に**4営業日の空き**(パージ)を置く。
- 各銘柄の最初の1行と、末尾の5営業日は欠損(`ret_fwd1` は末尾1日)。窓に欠損があれば欠損(補完しない)。
- 個別株は極端な値がある(日次リターンの最大が+330%など)。外れ値のクリップは、**学習時だけ・学習データの分位点で**行い、評価は元の値でも報告する(提案。分割を決めるときに確定)。
- 作者の `forward_return` / `market_impact`、NYTの `Label` は、目的変数に使わない(参照のみ。`forward_return` は `|ret_fwd1|` として再現できることを確認済み)。

## 2. 説明変数
### 2-1. 共通ルール
- すべて、**起点(t の引け後)までに公開された情報**だけ。「t+1 以降の価格を変えても、行 t までの特徴量が変わらない」ことをテストで保護する(`tests/test_numeric_features.py`)。
- 欠損は作成時に補完しない。モデル側で扱う(線形は学習データの中央値 + 欠損フラグ、勾配ブースティングは欠損のまま)。
- スケール・外れ値は、学習データだけで決める(§0-3)。対数変換・クリップは `own_volume_ratio` などで検討する。

### 2-2. 数値(A0 / A0m)
| グループ | 個数 | 研究1(A0m) | 研究2(A0) |
|---|---|---|---|
| 銘柄(`own_*`): リターン・実現ボラ・レンジ・ギャップ・出来高比・移動平均/52週高値からの距離 | 10 | — | ○ |
| 市場・マクロ: S&P500・VIX・金利・為替・商品・SOX−NASDAQ | 15 | ○ | ○ |
| カレンダー: 曜日・月(t の日付そのもの) | 2 | ○ | ○ |
| **合計** | | **17** | **27** |

- 名前と式は `src/features/numeric.py`。**行 t の値は、t の終値までから計算した値(当日を含む)**。例えば `own_ret_1d` は日 t のリターン、`own_ret_5d` は t までの5営業日のリターン。
- **A0の特徴量セットは、テキストを足す前に確定して凍結する**。凍結後は変えない(変えるなら理由を記録し、A0〜A3 を全部作り直す)。27個は初期案。確定の手順は、分割を決めたあとに決める。

### 2-3. 世界情勢テキスト(NYT。A1 / A1m)
- 行 t には、**日付 D = t の見出し**を使う(過去の日付は §2-6)。見出しは日付のみで公開時刻がないため、引け後に出た見出しが混ざりうる。いずれも t+1 の寄り前までの情報で、目的変数(t+1 以降)より前なので、リークではない。
- 表現(案): FinBERTの感情(正・負・中立)、埋め込み(+PCA)。PCAなどの変換は、学習データだけで決める。
- 研究2では、全銘柄に同じ値を付ける。実質のサンプルは日数なので、日付でまとめて扱う。

### 2-4. 銘柄ニュース(news_price_events。A2 / A3)
- 行 `(ticker, t)` には、**取引日 t の行**(9〜15時の窓)をすべて使う。寄り前のニュース(前日の引け後〜t の寄り前)は t の9時の窓に入り、日中のニュースはそれぞれの窓に入る。
- 取引日 t の**16:00以降の437行は除外**する(`original_first_date` で判定)。引け後のニュースは、作者の処理により次の取引日の行に入る。
- 対象の(銘柄,日)は158,680(うち価格がある220銘柄で156,422)。1日に複数の窓がある(銘柄,日)は26.7%。(銘柄,日)ごとに、窓のテキストを集約する(方法は未決: 連結 / 窓ごとの特徴量の平均・最大など)。
- 表現(案): FinBERTの感情・埋め込み、見出し数、テキスト長。複数の銘柄に共通の汎用見出しは、フラグを付けて感度分析で除く。
- **当日のニュースへの反応は、当日の数値(t の終値までの値)に既に入っている。** A2は、数値で説明できない部分を、その後(t+1〜)の値動きについて予測するかを測る。

### 2-6. 過去の履歴の持たせ方(提案。未実装)
各行(銘柄, t)が、当日だけでなく**過去の情報を引き継ぐ**ようにする。すべて **t までの日付だけ**で作る(未来は見ない)。
- **数値**: 過去の窓の要約で既に持っている(リターン1・5・20日、実現ボラ5・20日、移動平均・52週高値からの距離、VIX・金利・為替・商品の5日変化)。必要なら、主要な特徴量の1〜数日前の値(ラグ)を追加する。
- **銘柄ニュース**: 当日の特徴に加えて、**過去 k 日(k=5・20など)の集計**を持つ — ニュースの件数、感情の平均、最後のニュースからの日数。ニュースがない日は、0件・欠損 + フラグ(`has_news`)。
- **NYT**: 当日(D = t)に加えて、過去 k 日(k=5など)の移動平均。
- 作り方: 記事単位の特徴(`data/interim/`)を日付順に累積して、(銘柄, t) ごとに集約する(`data/processed/`)。**raw → interim(記事単位)→ processed(日次 + 履歴)の流れで、過去の日付のデータは、新しい行から参照できるように保持する。**

## 3. 行の選び方
- **全条件で、同じ行を使う**(条件ごとに行を変えない)。ある条件で説明変数が欠損している行は、全条件から外す。
- 研究1: 行 = 営業日 t(SPY)。研究期間 2009-04-29〜2020-06-12 で2,801日(NYTと重なるのは2,799日)。NYTの全期間(2008〜2021、3,522日)は頑健性確認に使う。
- 研究2: 主な比較は、「当日のニュースがある(銘柄,日)」(156,422行)。補助として、全日 + ニュースの有無フラグ。
