# 研究1 A0m・A1m: 水準系の特徴量を外した検証 × XGBoost(2026-10-15 作成)

## 1. 概要
SHAP で突出していた `tnx_level`(10年金利の水準)と、同じく時期とともにずれる水準系を外して、同じ評価をやり直した。**予測力は戻らず、結論は変わらない**: 方向は当てられず、NYT感情の上積みも見えない。一方、2013年の見かけの R²(+0.05)は `tnx_level` に由来すると確認できた。

## 2. 条件
- 行・目的変数・分割・モデル(reg1/reg2)は、[A0m](20261015_study1_A0m_numeric_xgboost.md) と同じ(共通3,211行、年ごとに学習を足す walk-forward、2013〜2021)。
- 外した特徴量(行は変えない):
  - **−tnx**: `tnx_level` の1個(A0m 17列 / A1m 22列)
  - **−3水準**: `tnx_level`、`term_spread`、`vix_level` の3個(A0m 15列 / A1m 20列)
- 確認期間(2018〜2021)は開封済みのため、探索的な結果として扱う。

## 4. 考察
- **予測力は戻らない。** 外した後も、開発・確認とも R² は約0(±0.01)、AUC は 0.46〜0.50 で偶然以下〜偶然。上昇と予測した割合もほぼ96〜100%。
- **2013年の R² +0.056 は、`tnx_level` の寄与だった。** 外すと +0.009 に下がる(2021年も +0.045 → +0.024)。方向を当てた結果ではなく、時期の水準を拾った効果と整合する。
- **年別のばらつきは小さくなった。** 外すと2013〜2017年がおおむね同じ大きさ(+0.00〜+0.016)に揃い、「特定の年だけ当たる」状態はなくなった。ただし、水準が正のまま続いているわけではなく、確認期間では0か負。
- **NYT感情の上積みはここでも見えない。** 確認期間で A1m − A0m は、−tnx で reg1 −0.0156、reg2 +0.0004。
- 言えること: 「この数値特徴量(水準系を外しても)では、5日平均リターンの方向を予測できない」。言えないこと: 「テキストが無効」(基準に予測力がないため、差を測れない)。
