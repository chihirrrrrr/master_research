# 研究1 A0m・A1m: 単純な前80%/後20%分割 × XGBoost(2026-10-15 作成)

## 1. 概要
全期間(2008〜2021)を時間順に**前80%で学習、後ろ20%でテスト**する、単純な1回の分割で評価した(年ごとの学び直しはしない)。数値のみ(A0m)と +NYT(A1m)を比べた。**どちらも予測力はほぼなく、A1m の改善も見られない。** 確認期間(2018〜2021)を含むため、探索的な結果として扱う。

## 2. データセット
共通 3,211 行(2008-01-31〜2021-12-23)。A0m 18列、A1m 23列。説明変数・目的変数は [A0m](20261015_study1_A0m_numeric_xgboost.md) / [A1m](20261015_study1_A1m_numeric_nyt_xgboost.md) のメモと同じ。

## 3. モデルと設定
XGBoost 回帰、reg1・reg2、5シード平均(設定は A0m のメモ §5)。

## 4. データの分け方
```
学習   2008-01-31 〜 2019-05頃   2,565行(前80%。境界4行を除く)
空き   4営業日
テスト 2019-05-07 〜 2021-12-23     642行(後ろ20%)
```
- 学習の内側の後ろ20%(4行の空き付き)で、深さ・min_child_weight・木の数を選び、学習全体で学び直してテストを予測する。
- テストは1回の予測のみ(年ごとの再学習なし)。テスト期間には2019年後半、2020年(コロナ急落)、2021年が入る。
- 手順は、確認期間を使うことを承知で、あなたの指示(2026-10-15)により実行した。

## 6. 考察
- **年ごとの再学習と、結論は同じ。** 正解率は「いつも上昇」と同じで、予測はほぼ定数(予測sd 0.4〜2.3 bp、実現 56 bp)。上昇と予測した割合は100%。
- **AUC は 0.52〜0.55 と、年別(約0.46〜0.48)よりわずかに高い。** ただし1回の検定ブロックで、ばらつきが大きい。R² は +0.003〜+0.005 と、履歴平均に対してごく小さい改善。
- **Clark–West は reg2 の A0m で p=0.02。** ただし予測sdが 0.4 bp と、ほぼ定数で、1ブロックの結果。多重比較(4条件)も考慮すると、強い根拠にならない。
- **NYT感情の上積みは、ここでも見えない。** R² の差は +0.0016(reg1)、+0.0005(reg2)で、AUC は reg1 で +0.005、reg2 で −0.021。
- 言えること: 「単純な前80%/後20%でも、この18〜23個では、方向を当てられない」。年ごとの再学習と合わせて、結論は変わらない。
