# 研究1 A0m: 数値のみ × XGBoost(2026-10-15 作成)

## 1. 概要
S&P500の5日先の平均リターンを、数値18個だけで予測した(基準条件 A0m)。**予測力はほぼない**: 正解率は「いつも上昇」と同じ、AUCは偶然以下(約0.47)、R²は約0。

## 2. データセット
- 行 = S&P500の営業日。`data/processed/market_features.parquet` + `market_targets.parquet`
- 比較対象(A1m)と行を揃えるため、NYT感情が揃う行に絞った(**共通 3,211 行**、2008-01-31〜2021-12-23)。全行は 3,499。
- 説明変数 18 列、目的変数 1 列(主)。

## 3. 説明変数(18個。すべて取引日 t の終値までの情報)
| グループ | 名前 | 意味 |
|---|---|---|
| S&P500の値動き(6) | `spx_ret_1d` `spx_ret_5d` | 当日 / 直近5日のリターン |
| | `spx_rv_20d` | 直近20日の日次変動の標準偏差 |
| | `spx_range_1d` `spx_gap_1d` `spx_close_loc` | 当日の値幅÷終値 / 始値の前日終値からのずれ / 終値の高安内の位置(0〜1) |
| VIX(3) | `vix_level` `vix_chg_1d` `vix_term` | 水準 / 前日比(対数)/ VIX3M÷VIX |
| 金利(3) | `tnx_level` `tnx_chg_5d` `term_spread` | 10年債利回りの水準 / 5日変化 / 10年−3か月 |
| 商品・業種(4) | `wti_ret_5d` `copper_ret_5d` `gold_ret_5d` | 原油・銅・金(先物)の5日リターン |
| | `sox_minus_nasdaq_5d` | 半導体指数5日リターン − NASDAQ5日リターン |
| カレンダー(2) | `dow` `month` | 曜日 / 月 |
為替は、2008年のデータ破損のため除外。

## 4. 目的変数
`spx_ret_fwd5` = S&P500(^GSPC)の日次リターンの **t+1〜t+5 の平均**(t を含まない)、単位 bp(1bp=0.01%)。日次リターンは前日終値→当日終値。予測の起点は取引日 t の引け後。

## 5. モデルと設定
XGBoost(回帰 `reg:squarederror`、hist)。標準化なし。5シード(0〜4)の予測平均。

| 項目 | reg1 | reg2 |
|---|---|---|
| 木の深さ(探索) | 1, 2 | 1 |
| min_child_weight(探索) | 50, 100 | 100, 200 |
| 学習率 | 0.02 | 0.01 |
| 木の数の上限 / early stopping | 400 / 30 | 300 / 30 |
| subsample / colsample | 0.7 / 0.5 | 0.6 / 0.5 |
| reg_lambda | 50 | 200 |
設定ファイル: `configs/study1_xgb_reg1.yaml`, `study1_xgb_reg2.yaml`

## 6. データの分け方
**年ごとに学習を足していく方式(walk-forward、拡張窓)**。単純な「前80%/後20%」ではない(それは別メモ: [単純80/20](20261015_study1_A0m_A1m_simple8020_xgboost.md))。

```
1回目: 学習 2008-02〜2012末   →  テスト 2013年   (学習 1,147行 / テスト 237行)
2回目: 学習 2008-02〜2013末   →  テスト 2014年   (学習 1,384行)
 …(毎年、学習を1年分足して再学習)…
9回目: 学習 2008-02〜2020末   →  テスト 2021年   (学習 2,960行 / テスト 247行)
```
- 学習とテストの間に **4営業日の空き**(目的変数が t+1〜t+5 を使うため)。
- 各回の学習データの**内側**で、後ろ20%を「設定選び用の検証」に使う(テストの20%とは別物)。
  1. 学習の前80%で、候補(深さ・min_child_weight)ごとに学習する。
  2. 後ろ20%(4行の空きを挟む)で誤差(RMSE)が最小の設定と木の数を選ぶ。
  3. 選んだ設定で、その回の学習データ全体を使って学び直し、テスト年を予測する。
  テスト年は設定選びに使わない。
- 年の区分: 開発 2013〜2017(5年)、確認 2018〜2021(4年。2026-10-08に開封済み)。**年ごとの結果は、9年すべてを下に載せる**。
- 全行 3,211 のうち、最初の学習 1,147行(約36%)、テスト年の合計 2,060行(約64%)。単純な割合では評価しない(各年は、その時点の過去だけで予測した結果)。

## 8. 考察
- **方向の予測力はない。** 9年とも、上昇と予測した割合はほぼ100%で、的中率は「いつも上昇」と同じ。AUC は 0.42〜0.60 の間で年により振れ、平均すると偶然(0.5)付近。
- **R² は年ごとにほぼ0で、年により符号が変わる。** 正に大きいのは2013年(+0.056)と2021年(+0.045、reg1のみ)。負は2018年(−0.018)、2016年・2020年(reg1)。
- **2013年の R² は、方向を当てた結果ではない。** 相関は −0.017、AUC は 0.42。予測がほぼ定数なので、平均の水準が履歴平均より近かった分にすぎない。一方2021年(reg1)は相関 +0.35、AUC 0.60 で、方向もやや当たっているが、reg2 では +0.006 に下がり、設定により不安定。
- **学習側はわずかに信号を拾うが、テストに持ち越されない**(§7.3)。強い過学習ではなく、弱い規則性が時期をまたいで続かない状態。reg2 は学習側でも定数に近い(2017年の予測sd 0.2 bp)。
- **`tnx_level`(10年金利の水準)が突出**(§7.4)。水準は期間中に単調に動くため、時期の代理変数になり、学習期間の傾向をテスト年に持ち込む可能性がある。変化量や正規化への置き換えが次の検証候補。
- 言えること: 「この18個では、5日先の市場リターンの方向を、年ごとの再学習で予測できない」。言えないこと: 「数値からは一般に予測できない」(目的変数・特徴量・期間を変えると結果は変わりうる)。
