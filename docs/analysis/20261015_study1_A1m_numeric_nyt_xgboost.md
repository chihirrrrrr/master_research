# 研究1 A1m: 数値 + NYT感情 × XGBoost(2026-10-15 作成)

## 1. 概要
A0m(数値18個)に、NYT見出しのFinBERT感情5個を足して、同じ予測を行った(A1m)。**A0m に対する安定した改善は見られない**: 年別の R² の差は小さく、年と設定により向きが逆転する。

## 2. データセット
- A0m と同じ共通 **3,211 行**(2008-01-31〜2021-12-23)。行・分割・モデルを揃え、違いは入力列だけ。
- 説明変数 **23 列** = A0m の18 + NYT感情 5。目的変数は A0m と同じ。
- NYTは「World」欄の見出し(1日1行)。`data/raw/nyt_headlines`(CC0)。感情は `data/processed/nyt_features.parquet`。

## 3. 説明変数
A0m の18個は [A0mのメモ](20261015_study1_A0m_numeric_xgboost.md) §3 を参照。追加の5個(いずれも取引日 t までの見出し):

| 名前 | 意味 |
|---|---|
| `nyt_pos` | 当日の見出しがポジティブである確率(FinBERT) |
| `nyt_neg` | ネガティブである確率 |
| `nyt_neu` | 中立である確率 |
| `nyt_net_ma5` | (pos − neg) の直近5日平均 |
| `nyt_neg_ma5` | neg の直近5日平均 |
FinBERT = ProsusAI/finbert。見出しがない日(62日)を含む5日窓は欠損にし、行を落とした(3,499 → 3,211)。

## 4. 目的変数
A0m と同じ。`spx_ret_fwd5` = S&P500の日次リターンの t+1〜t+5 の平均(bp)。

## 5. モデルと設定
A0m と同じ(XGBoost 回帰、reg1 / reg2、5シード平均。表は A0m の §5)。

## 6. データの分け方
A0m と同じ(年ごとに学習を足す walk-forward。2013〜2021の9年。詳細・図は [A0mのメモ](20261015_study1_A0m_numeric_xgboost.md) §6)。学習の内側の後ろ20%は、設定選び用の検証。確認期間 2018〜2021 は開封済み。

## 8. 考察
- **NYT感情を足しても、数値のみに対する安定した改善はない。** 年別の R² 差は ±0.04 以内で、符号は年により変わる(reg1 は9年中7年が悪化、reg2 は9年中7年が改善〜同等だが、差はいずれも小さい)。
- **年ごとの振れ幅が、平均の差より大きい。** reg1 の2017年は A1m が −0.033 と大きく悪化(深さ2・木333本という複雑な木が選ばれた年)、reg2 の2017年は +0.033 と改善。
- **方向の予測は改善しない。** 的中率は「いつも上昇」とほぼ同じ、上昇と予測した割合はほぼ100%。AUC は 0.40〜0.61 で年により振れる。
- **学習側では A1m の方がやや強く当てはまる**(2016〜2017年の R²_in が約0.15、AUC 0.66)が、テスト側の改善はこれに見合わない。特徴量が増えた分、学習データに合わせやすくなっただけの可能性がある(reg1)。
- **SHAP でも NYT感情の寄与は小さい。** 上位は `tnx_level` を筆頭に数値特徴量。
- 言えること: 「この設計(市場全体・日次・5日平均・1日1行のNYT感情)では、NYT感情による改善は検出できない」。言えないこと: 「テキストは無効」(基準の A0m 自体に予測力がなく、差を測る土台が弱い)。
- 次の検証: 研究2(個別銘柄・銘柄ニュース)、水準系特徴量の置き換え、目的変数の変更(翌日リターンなど)。
