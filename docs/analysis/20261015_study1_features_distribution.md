# 研究1 特徴量の分布(A0m 18個 + NYT 5個)(2026-10-15 作成)

## 1. 概要
23個の特徴量の分布を、共通 3,211 行(2008-01-31〜2021-12-23)で調べた。**分布の形(外れ値・歪み)よりも、「水準系の特徴量が時期とともにずれていく」ことが主な問題**。木のモデル(XGBoost)はスケールの違いには影響されないが、時期のずれと冗長な特徴量は無視できない。

## 3. 気づいたこと

### 3.1 水準系は時期とともにずれる(最重要)
`tnx_level`(10年金利)、`term_spread`(長短金利差)、`vix_level` は、2008〜2012年と2013年以降で平均が約1標準偏差ずれている。年別の平均:

| 年 | tnx_level | term_spread | vix_level |
|---|---|---|---|
| 2008 | 3.64 | 2.44 | 33.7 |
| 2012 | 1.79 | 1.71 | 17.8 |
| 2017 | 2.33 | 1.40 | 11.1 |
| 2019 | 2.13 | 0.10 | 15.3 |
| 2020 | 0.89 | 0.55 | 29.0 |
| 2021 | 1.44 | 1.41 | 19.7 |
- 2020年の `tnx_level` は、それ以前の年別平均(1.4〜3.6)の範囲外。木は学習期間の範囲外では、端の値で答えるだけになる。
- 水準は時期を表す代理変数になりやすく、SHAP で `tnx_level` が突出した理由と整合する(§5)。

### 3.2 外れ値・重い裾
- 尖度が大きい: `spx_gap_1d`(72.8)、`nyt_pos`(34.6)、`wti_ret_5d`(30.2。2020年4月の原油の異常値の影響)、`spx_range_1d`・`spx_rv_20d`(13〜17)。
- 変動系(`spx_rv_20d`、`spx_range_1d`、`vix_level`)は右に歪む(歪度 +2.4〜+3.4)。対数をとると形が整う。
- 平均から5標準偏差以上の日が、`spx_rv_20d` 30日、`spx_range_1d` 27日、`nyt_pos` 22日、`spx_gap_1d` 19日などある。

|---|---|

- NYTの5列のうち、実質の情報は2〜3個分。

### 3.4 形の特徴
- `spx_close_loc` は0〜1の範囲で、0と1に偏る(二峰)。
- `dow`(5値)と `month`(12値)は、カテゴリを数値として入れている。木では問題ないが、GRUなどでは別の扱い(one-hot など)が要る。
- NYT感情の平均は net −0.51(ほとんどの見出しが「ネガティブ」と判定される)。世界ニュースの見出しの性質で、日々の変動(標準偏差 0.14)は小さい。

## 4. 正規化は必要か
- **XGBoost(木のモデル)**: スケールや単調な変換(標準化・対数)には影響されない(確認済み)。外れ値も、分割点に影響しにくい。**正規化は不要**。
- **GRU・線形モデル**: 必要。学習データの平均・標準偏差で標準化し、`spx_gap_1d`・`nyt_pos`・`wti_ret_5d` は 1%/99% で切る(クリップ)、変動系は対数をとる。
- **水準系の時期のずれ**は、スケールの問題ではなく、「どの時期の値か」の問題。標準化では解決しない。

## 5. 次にやること(案)
1. 水準系を、変化量や、ローリング252日の平均からのずれに置き換えて、同じ評価をやり直す。
2. `nyt_neg_ma5`(または `nyt_net_ma5`)と `nyt_neg` を外した版を試す(冗長の整理)。
3. GRU を使うときは §4 の前処理を、学習データの統計だけで行う。
