# 研究1 A0m・A1m: 累積リターンの期間(5・10・20日)の比較 × XGBoost(2026-11-19 作成)

## 1. 概要
目的変数を **5日・10日・20日の累積リターン**にして、同じ分析(数値のみ A0m と +NYT A1m、reg1・reg2、2013〜2021の年ごとの walk-forward)を行い、精度を比べた。**期間を延ばしても、方向は当てられない**。10日で開発期間の R² がやや高く見えるが、年ごとの振れが大きく、AUC は偶然付近で、確認期間では全期間で R² が負になる。20日では AUC が **0.5を下回る**(順序が逆)。NYT感情の上積みは、どの期間でも一貫しない。

## 2. 目的変数と条件
| 期間 | 目的変数 | 式 | 学習とテストの境界の空き | 使える行(共通) |
|---|---|---|---|---|
| 5日 | `spx_cum_fwd5` | (終値_{t+5} ÷ 終値_t − 1) × 10,000 bp | 4営業日 | 3,211 |
| 10日 | `spx_cum_fwd10` | (終値_{t+10} ÷ 終値_t − 1) × 10,000 bp | **9営業日** | 3,206 |
| 20日 | `spx_cum_fwd20` | (終値_{t+20} ÷ 終値_t − 1) × 10,000 bp | **19営業日** | 3,196 |
- **空きを期間に合わせた**: 目的変数が t+1〜t+h を使うので、境界には h−1 日の空きが必要(足りないと、学習の目的変数がテスト期間の値動きを含み、リークになる)。`configs/study1_xgb_reg{1,2}_cum{10,20}.yaml` の `embargo_days` で指定し、run の `config.yaml` の `embargo_days_used` に記録した。
- 末尾 h 日は目的変数が欠損のため、行が少し減る(5日 3,211 → 20日 3,196)。
- 説明変数(A0m 18個 / A1m 23個)、モデル(reg1・reg2、5シード)、分け方(2013〜2021、開発 2013〜2017 / 確認 2018〜2021)は、5日の分析と同じ([A0m](20261015_study1_A0m_numeric_xgboost.md))。確認期間は開封済みのため、探索的な結果として扱う。

R² は予測をつないだ値(物差しは、その回の学習データの平均)。AUC の 0.5 は偶然。表は `results/analysis/horizon_compare.md`(`python -m src.analysis.compare_horizons`)から作った。

## 4. 考察
- **期間を延ばしても、予測できるようにはならない。** 正解率はどの期間でも「いつも上昇」と同じか、それ以下。上昇の割合が期間とともに上がる(5日 0.632 → 10日 0.673 → 20日 0.704)ので、基準が高くなり、正解率だけを見ると良く見える点に注意。
- **10日の開発期間 R²(+0.03〜+0.05)は、方向を当てた結果ではない。** 年別の R² は −0.069〜+0.085 と符号が入り乱れ、AUC は 0.35〜0.71 で偶然の周りを振れる。確認期間では、10日の R² は −0.007〜−0.011 と負。
- **20日は AUC が 0.38〜0.44 と、開発・確認とも 0.5 を下回る。** 予測の大小が、実際の上昇・下降と逆順に並んでいる。符号を反転して使うことはできない(結果を見てからの後付けになるため)。学習期間の規則性が、テスト期間では逆に働いたことを示す。
- **確認期間(2018〜2021)の R² は、全期間・全条件で負**(5日 −0.001〜−0.003、10日 −0.007〜−0.011、20日 −0.006〜−0.014)。5日より、10日・20日の方が負が大きい。
- **SHAP は、どの期間でも `tnx_level`(10年金利の水準)が1位**(寄与の約3割)。10日・20日では `month`(月)が上位に入り、時期の代理を拾っている兆候。モデルが使っているのは、時期に結びついた水準で、これが持ち越されない原因と整合する。
- **NYT感情の上積みは、一貫しない。** ΔR²(A1m − A0m)は、開発で −0.013〜+0.011、確認で −0.0002〜+0.007と小さく、年別に改善した年も 3〜7 / 9 とばらつく。
- **注意(統計)**: 累積リターンは隣の日と大きく重なる。独立な観測は、およそ日数 ÷ 期間(5日で約640、10日で約320、20日で約160)に減り、結果のぶれが大きくなる。run に保存している Clark–West の p 値は、重なりの補正が 5 日分のため、10日・20日では甘く出る。この比較では p 値を使っていない。
- 言えること: 「5・10・20日のどの累積リターンでも、この数値特徴量では方向を予測できず、NYT感情を足しても一貫した改善はない」。言えないこと: 「長期の予測が不可能」(目的変数・特徴量・手法が変われば結果は変わりうる。また20日の逆順は、1つのデータでの観察)。
