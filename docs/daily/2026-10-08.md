## 2. 説明変数(研究1)
予測の起点は取引日 t の引け後。すべて t の終値までの情報(過去の窓を含む)。

**A0m: 数値 18個**(`src/features/market_level.py` → `data/processed/market_features.parquet`)
- S&P500(^GSPC)のOHLC由来(リターン、レンジ、窓の統計など。うち3個はOHLC由来)
- 金利: irx_3m / fvx_5y / tnx_10y / tyx_30y 由来(水準と変化)
- 為替は入れない(上記の理由)

**A1m: A0m + NYT感情 5個**(`src/features/nyt_text.py` → `data/processed/nyt_features.parquet`)
- FinBERT(ProsusAI/finbert)でNYT「World」見出しを採点: `nyt_pos`, `nyt_neg`, `nyt_neu`
- `nyt_net_ma5` = (pos−neg) の直近5日平均、`nyt_neg_ma5` = neg の直近5日平均(当日を含む過去のみ)
- 見出しがない日(62日)を含む窓は欠損 → 比較は両条件で**同じ行(共通 3,211行)**に揃える

## 3. 目的変数
- 主: `spx_ret_fwd5` = ^GSPC の日次リターンの **t+1〜t+5 の平均**(t を含まない)、単位 bp
- 副: `spx_ret_fwd1`(翌営業日)
- 日次リターン r_s = 前日終値→当日終値。ラベルは価格から作り直した(既存ラベルは使わない)
- 研究2(未着手)では `ret_fwd5` と超過リターン `ex_ret_fwd5`(銘柄−SPY)

## 4. 学習方法
- **評価の枠組み: walk-forward(拡張窓)**。初回学習 2008-02〜2012(1,235日)→ 年ごとに2013〜2021をテスト、毎年、学習を延ばして再学習。
  - 学習とテストの境界に **4営業日の空き**(目的変数が t+1〜t+5 を使うため)
  - 開発期間 2013〜2017、最終確認 2018〜2021(`--final` を付けたときだけ評価)
  - A0m と A1m は同じ行・同じ分割・同じモデル。違うのは入力列だけ
- **モデル: XGBoost(回帰、hist)**。学習データの**後ろ20%を検証**(時間順、4日の空き)にして、`max_depth × min_child_weight` のグリッド探索と early stopping。決まった木の数で全学習データに再学習し、**5シードの平均**を予測とする。
  - default / reg1(depth 1–2, min_child_weight 50–100, lr 0.02, colsample 0.5, lambda 50) / reg2(depth 1, mcw 100–200, lr 0.01, subsample 0.6, colsample 0.5, lambda 200)
  - 標準化は木のモデルでは効果なし(確認済み)。バッチサイズはない
- **指標**: 標本外R²(拡張した履歴平均が物差し)、RMSE、相関、方向の的中率、balanced accuracy、F1(上昇)、AUC、予測の標準偏差(ほぼ定数の予測の検出)
- **検定**: Clark–West(HAC lag 5)、複数比較は Holm 補正

## 5. 結果
| 設定 | 結果 |
|---|---|
| A0m 開発期間 R² | default −0.0036(2017年 −0.263)/ reg1 +0.0001 / reg2 +0.0071 |
| reg2 の中身 | 予測の標準偏差 1.5〜3.8 bp(実現 29.8 bp)、AUC 0.46〜0.49 → **ほぼ定数の予測**。「安定」ではなく、何も学べていない。「いつも上昇」の的中率は 0.616 |
| A0m vs A1m(共通3,211行、開発) | ΔR² reg1 −0.0058 / reg2 +0.0042 |
| 2013〜2021 全体(2,060日) | reg1 ΔR² −0.0027 (p=0.622) / reg2 +0.0010 (p=0.113)。Holm後は有意でない |
| 最終確認期間の A0m R² | reg1 −0.0005 / reg2 −0.0023 |
| 診断 | 単純な80/20(全データ)ではテストが2019-05-06以降=確認期間に入る。開発期間内の80/20(学習1,820/テスト457)では R² +0.003〜+0.017、AUC 0.52〜0.54、+NYTがわずかに良いが p=0.11〜0.37。学習曲線は単調でない |

解釈: 5日平均リターンは信号が弱く、数値のみで基準を超えない。NYT感情の上積みも、この設計・期間では見えない。
