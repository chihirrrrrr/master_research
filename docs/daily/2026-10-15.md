# 日報 2026-10-15

## 1. 今日の結論
- **研究1(市場レベル、S&P500)で、5日平均リターンを数値特徴量から予測することは、この設計ではできない**と確認した。確認の方法: 学習側の指標、SHAP、単純な前80%/後20%、水準系の特徴量の除外。どれでも結論は同じ。
- **NYT感情を足しても、数値のみに対する安定した改善は検出できない**(年別の差は小さく、年と設定で向きが変わる)。
- ただし「テキストは無効」とは言えない。基準(数値のみ)に予測力がなく、差を測る土台がない。
- 見かけの R²(2013年 +0.05)は、10年金利の水準(`tnx_level`)が時期の代理になっていた効果。外すと消える。
- **リターンでの研究1の分析は、ここで終える。** 次は、目的変数をボラティリティ(変動の大きさ)にする探索(次回)。
- 今日の分析は `docs/analysis/` に、1回の分析ごとに1ファイルとして残す運用を始めた。

## 3. 今日やったこと(流れ)
1. **学習データ側の指標を追加**: 学習側の正解率・AUC・R²を出した。**学習側はわずかに信号を拾う(AUC 0.57〜0.63)が、テストに持ち越されない**。
2. **SHAP(XGBoost内蔵の厳密解)を追加**: 全条件で `tnx_level` が突出(2位の約3倍)。NYT列の寄与は小さい。
3. **特徴量の分布を調べた**: 水準系(`tnx_level`、`term_spread`、`vix_level`)が時期でずれる。重い裾、冗長な特徴量(NYTの5列は実質2〜3個分)も確認。
4. **分析メモの運用を開始**: `docs/analysis/` に、日付・研究・データ・モデルが分かる名前で保存。構成は固定。
5. **結果の見せ方を修正**: 「テスト行をつないだ全体」の表をやめ、年別(2013〜2021)を主にした(意図は年ごとの再学習)。
6. **単純な前80%/後20%を実行**: 結論は同じ(正解率は「いつも上昇」と同じ、予測は定数に近い)。
7. **水準系を外した検証**: `tnx_level` のみ、水準系3つ。予測力は戻らない。2013年の R² は消える。
8. 目的変数の見直しを相談し、**ボラティリティを次の研究で探索する方針**に決めた(価格の水準予測は、見かけだけ高精度になるため採らない)。

## 4. 結果(要点)
| 項目 | 結果 |
|---|---|
| 数値のみ(A0m)の予測力 | 正解率は「いつも上昇」と同じ(約0.63)、AUC 0.46〜0.50、R² ≈ 0 |
| +NYT(A1m)の上積み | 年別の R² 差は ±0.04 以内で、向きが年と設定で変わる。有意でない |
| 学習側 vs テスト側 | 学習側 AUC 0.57〜0.63 → テスト 0.46〜0.50。強い過学習ではなく、弱い規則性が持ち越されない |
| SHAP | `tnx_level` が1位(約3倍)。次は `spx_rv_20d`、`vix_level`、`spx_ret_5d` |
| 水準系を外す | R² は約0のまま、2013年の +0.056 は +0.009 に。確認期間は 0か負 |
| 単純80/20 | R² +0.003〜+0.005、AUC 0.52〜0.55、予測sd 0.4〜2.3 bp(ほぼ定数) |
